# Robichip Official Website

This repository contains a static website template for **Robichip Technology Co., Ltd.** (羅比芯科技).  Use this as a starting point for publishing your company's web presence on GitHub Pages or another static hosting service.

## Contents

- `index.html` – the main landing page introducing your company and its services.
- `v3/index.html` – a placeholder page for version 3 products.
- `V2/index.html` – a placeholder page for version 2 products.
- `v1/index.html` – a placeholder page for the original version.
- `assets/style.css` – a simple stylesheet used by all pages.

The HTML files are written in Traditional Chinese (zh‑Hant) and include placeholder text describing Robichip's mission, products and history.  Feel free to replace or expand upon this content.

## Publishing on GitHub Pages

To publish this site on GitHub Pages:

1. Create a new repository on GitHub (for example, `robichip.github.io`).
2. Clone the repository locally and copy the contents of this template into it.
3. Commit and push the files to GitHub.
4. In your repository settings, enable GitHub Pages. Choose the `main` branch and set the root folder (`/`) as the source.

After a few minutes, your site will be available at `https://yourusername.github.io/`.
