Why RobiTorque

Torque Density Becomes the Next System Bottleneck

扭力密度是機器人致動器的下一個瓶頸

Robotics actuators are constrained by torque density, module volume, thermal path, control integration, and reliability under dynamic load.

機器人致動器的瓶頸不只在馬達或控制演算法，而在扭力密度、模組體積、 熱路徑、控制整合與動態負載下的可靠度。

Torque Density

Higher Torque in Smaller Modules

更小體積中的更高扭力

Robotics joints and servo modules need compact high-power-density drive solutions to reduce actuator size and integration friction.

Thermal Path

Package-to-Structure Heat Flow

從封裝到結構的熱路徑

Heat must move from power stage and package into the mechanical structure without compromising reliability or control behavior.

Control Layer

FOC / Encoder / CANBus / RS-485

控制介面與韌體整合

Actuator systems require configurable control interfaces, position feedback, current sensing, and application-specific control firmware.

Validation

Dynamic Load and T-N Curve

動態負載與扭力轉速曲線

RobiTorque should move actuator discussion from datasheet assumptions to measurable dynamic-load and thermal validation.

Validation Tracks

Robotics Actuator Validation Tracks

機器人致動器驗證方向

RobiTorque can be organized into validation tracks for joint actuators, servo modules, compact motion systems, and future dexterous-hand actuation.

RobiTorque 可依驗證方向整理為關節致動器、伺服模組、緊湊型運動系統， 以及未來靈巧手致動方向。

RobiTorque-J

Joint Actuator Validation

關節致動器驗證

For robot joints, humanoid joints, robot dogs, and compact actuator modules requiring torque density, thermal-path review, and control integration.

RobiTorque-S

Servo Module Validation

伺服模組驗證

For industrial servo, AMR / AGV motion, gimbal, and automation nodes requiring compact drive electronics and measurable system behavior.

RobiTorque-G

Gimbal / Compact Motion

雲台與小型運動控制

For gimbal, pan-tilt, camera-stabilization, and compact robotic motion systems where smooth control and thermal stability are critical.

RobiGrip Roadmap

Dexterous Hand Actuation

靈巧手與緊湊致動路線

Future compact actuation roadmap for dexterous-hand or small-form-factor robotic motion, linked to RobiGrip and lower-power RobiSoC directions.

Public positioning: RobiTorque is currently a planned actuator validation platform and pilot collaboration track. Detailed configurations will depend on motor type, gear ratio, torque range, control interface, encoder feedback, mechanical structure, and thermal requirements.

對外定位：RobiTorque 目前為規劃中的致動器驗證平台與 pilot 合作方向。詳細組態將依馬達類型、 減速比、扭力範圍、控制介面、encoder feedback、機構結構與熱需求而定。
RobiDev + RobiLab

From Motor Drive Evaluation to Actuator Validation

從馬達驅動評估到致動器驗證

RobiDev provides the early motor-drive evaluation platform, while RobiLab supports dynamic-load, T-N curve, temperature-rise, and board-to-system validation.

RobiDev 提供早期馬達驅動評估平台，RobiLab 則支援動態負載、T-N curve、 溫升與 board-to-system validation。

RobiTorque Validation Flow｜RobiTorque 驗證流程

1. Requirement torque, speed, voltage, interface
2. Motor Drive RobiDev bring-up and control review
3. Dynamic Load T-N curve, load profile, torque behavior
4. Thermal Review driver, motor, structure heat path
5. Design-in Path RobiSoC RC25 / RC50 / RC75 / RC100 mapping
Recommended first pilot: use RobiDev Gen.1 and RobiLab measurement to validate motor-drive behavior, torque-speed behavior, thermal response, and control interface before committing to RobiSoC customization.

建議第一個 pilot：先使用 RobiDev Gen.1 與 RobiLab 量測能力，驗證馬達驅動行為、 扭力轉速行為、熱反應與控制介面，再進一步評估 RobiSoC 客製化導入。
Design-in Path

From Actuator Pilot to RobiSoC Design-in

從致動器 pilot 走向 RobiSoC design-in

RobiTorque is designed to help customers validate actuator requirements first, then map the system into the appropriate RobiSoC power class and control-layer strategy.

RobiTorque 的目標是先協助客戶驗證致動器需求，再將系統映射到合適的 RobiSoC 功率等級與控制層策略。

RC25

Compact Actuation

小型致動與教育平台

Suitable for compact motion, small actuators, education kits, and lower-power robotic modules.

RC50

Mid-power Servo

中功率伺服與關節模組

Suitable for servo modules, AMR / AGV motion, gimbal, and mid-power robotic actuation.

RC75

High-dynamic Actuator

高動態致動器

Suitable for high-dynamic joints, industrial motion, and higher torque-density robotic modules.

RC100

1000 W-class Indicator

高功率密度指標模組

Suitable for high-power-density joint actuator validation, advanced thermal-path review, and RobiSoC design-in discussion.
