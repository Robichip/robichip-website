RobiSoC Product Line

RC25 / RC50 / RC75 / RC100

從 250 W 到 1000 W 的可銷售 Power SoC 模組產品線

RC25, RC50, RC75, and RC100 share the same platform logic, pinout strategy, signal-interface direction, and M / G / T configuration structure. The main differences are power class, thermal envelope, and validation conditions.

RC25、RC50、RC75 與 RC100 採用一致的平台邏輯、PIN 定義方向、 訊號介面與 M / G / T 組態架構；主要差異在於功率等級、熱設計範圍與驗證條件。

SKU Logic

RCxx + M / G Defines the RobiSoC Product Configuration

以 RCxx + M / G 定義 RobiSoC 產品組態

RobiSoC SKU logic separates power class, controller option, GaN power-stage option, and compact thermal-model option. This allows the product family to keep a stable power platform while supporting customer-specific control and partner collaboration.

RobiSoC 的 SKU 邏輯將功率等級、控制器選項、GaN 功率級與 compact thermal model 分離定義。 這讓產品線維持穩定 power platform，同時支援客戶別控制需求與夥伴合作。

SKU Logic
RobiSoC-RCxx-MxGx
RCxx
RC25 / RC50 / RC75 / RC100 indicate 250 W / 500 W / 750 W / 1000 W power class
M1
STM32G4x-series motor-control MCU baseline, 170 MHz class, for early validation and standard reference design
M2
Custom controller / firmware integration option for MCU partners, system customers, and application-specific variants
G1
Integrated 100 V GaN half-bridge power-stage option
G2
100 V enhancement-mode GaN power transistor reference option
T1 / T2
Compact RC thermal-model options; final thermal parameters subject to package and system validation

Design-in Flexibility

Power Platform Without MCU Lock-in

避免被單一 MCU 綁死

RobiSoC keeps the power architecture, GaN module direction, thermal path, and validation workflow stable while supporting different control ecosystems.

Public positioning: M2 is a project-based control-layer option for MCU partners, system customers, education platforms, and application-specific reference designs. It is not positioned as a simple replacement of the M1 baseline controller.

對外定位：M2 是面向 MCU 夥伴、系統客戶、教育平台與特定應用 reference design 的專案型控制層選項， 不是單純取代 M1 baseline controller。
